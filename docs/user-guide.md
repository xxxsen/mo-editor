# 使用指南

## 打开游戏目录

Windows 桌面版从 [GitHub Releases](https://github.com/xxxsen/mo-editor/releases) 下载免安装程序后直接运行，需要 WebView2 运行时。点击「选择游戏目录」，选择包含游戏文件的目录，例如 `D:\MentalOmega`。程序会记住最近打开的目录。

编辑器优先读取目录根部的 `rulesmo.ini`；如果不存在，就从已选择的 MIX 中查找。页面右上角和属性来源显示实际使用的文件，点击主文件名称可以搜索并切换主文件。缺少 include 文件或检测到循环引用时，界面会提示。

通过「打开文件」也可导入 `rulesmo.ini`、`ra2md.csf` 和相关 MIX 文件。桌面版的单文件导入适合浏览和下载；直接保存需要选择游戏目录。导入文件夹时应保留 `[#include]` 使用的相对路径。

## 查找和编辑

- 在左侧选择步兵、载具、飞机、建筑、超级武器、武器、投射物或弹头，可按中文名、英文名、代码搜索，单位还可按所属国家筛选。
- 「全部对象」汇总已识别的各类对象；所属方筛选只作用于单位。全局参数可以通过左侧搜索定位，例如搜索 `RepairSell` 或「建筑自动维修」。
- 「全局配置」提供常规设置、战斗、电脑、难度、国家和阵营等规则段；「所有规则段」可浏览其他规则段。
- 已收录的字段显示为「中文名 / 规则字段名」，鼠标悬停查看说明。「全部属性」可搜索并添加已知字段，也可输入自定义字段。新字段留空只会显示在待编辑列表，填写值后才会产生修改。
- 国家、装甲、建造前置及已收录的固定选项可以搜索选择；逗号分隔的其他值可按原顺序分项编辑。未识别的现有选项会保留。

从武器、弹头或超级武器字段的「查看」可以进入关联对象；详情页也显示已识别的共享引用。使用顶部返回、前进按钮，鼠标侧键，`Alt+←` / `Alt+→` 或访问路径返回时，会恢复搜索、筛选、页签和滚动位置，并保留未保存修改。切换项目或主文件会清空浏览记录。

## 新建和复制

对象列表的「新增」和详情页的「复制并新建」支持步兵、载具、飞机、建筑、武器、投射物、弹头、超级武器和普通规则段。可以选择模板或空白创建，预览规则段、类型登记与保留的引用；确认后先加入草稿，点击「保存」才会写入。

游戏对象 ID 最多 24 个字符，普通规则段不受此限制。类型登记追加到已有列表末尾；如果没有对应列表，编辑器会创建列表。投射物列表用于编辑器管理，游戏效果仍需要武器引用。

复制单位时默认沿用武器、弹头、投射物和其他引用；未指定 `Image` 时复用模板图像，`UIName` 沿用模板，不会创建中文字符串或美术资源。空白对象需要自行补充必要属性。

「复制关联武器」可为选中的单位武器槽复制武器，并选择同时复制投射物、命中弹头及炸弹弹头。确认前会预览新增对象、类型登记和引用变化。操作只替换所选单位的一个武器槽；其他槽位、未选择的对象和子武器等仍共享。复制全局默认炸弹弹头时，新武器会单独引用副本，不会修改全局默认值。规则加载不完整时不能安全复制。

## 快捷功能和诊断

单位和建筑详情中的「快捷功能」可配置运输、驻军、自动产钱、隐形、探测、防护、初始乘员、建造条件、晋升、死亡爆炸和建筑超级武器。表单会带入已有值和未保存修改；预览列出新增、修改或移除的字段及来源，确认后加入草稿。建筑驻军可能影响建筑原有武器，界面会提醒。

「乘员车内开火诊断」检查普通、精英和编号武器的 `FireInTransport` 及已识别使用者。可以直接修改共享武器，也可以复制武器并替换该乘员的相关武器槽；复制后的弹头、投射物等仍共享。载具、目标和其他规则也会影响实际开火。

「建造条件诊断」可根据选择的国家、对局科技等级和模拟中已拥有的对象，检查类型登记、前置组、建造上限和候选生产建筑。「武器效果对照」可选择目标，查看装甲、命中弹头与炸弹弹头及其修正来源。诊断只依据已加载的规则，结果需要结合地图、模式和实际游戏状态判断。

具体字段和扩展引擎限制见[规则与兼容性](rules-reference.md)。

## 保存与历史版本

桌面版点击「保存」或按 `Ctrl+S`，将修改写回游戏目录。保存前会自动备份被覆盖的文件；如果文件自打开后被外部程序修改，保存会停止并保留草稿。「另存为」将主规则及已加载的 include 文件按相对路径输出到另一个目录，原项目草稿继续保留。

备份位于 `%LOCALAPPDATA%\local.mentalomega.ruleseditor\backups`，每个游戏目录独立保存。「历史版本」可以查看每次保存或恢复前后的差异，也可以预览从当前已保存文件恢复到目标版本的差异。确认恢复后只还原记录中列出的文件，并再次备份当前文件。

恢复会重新加载目录并丢弃所有未保存草稿；若磁盘文件或历史目标在预览后发生变化，恢复会停止。旧记录也可查看，快照缺失或损坏时界面会提示。对原本不存在的独立 INI，恢复时会移除生成的文件，不会把 MIX 中的内容当作历史快照。

历史差异支持 UTF-8、GBK、UTF-16 和换行变化。单文件超过 16 MB、行数过多或无法完整解码时，可下载对应快照后比较。未解析的 include、循环引用或不支持的继承会阻止直接保存，应先处理加载提示。

## 浏览器版

在项目目录启动本地静态服务器：

```sh
python3 -m http.server 4173 --bind 127.0.0.1
```

Windows 安装 Python 后也可以运行 `py -m http.server 4173 --bind 127.0.0.1`。打开 <http://127.0.0.1:4173/>，推荐使用最新版 Chrome 或 Edge；文件夹导入需要浏览器支持目录选择。浏览器版无需安装前端依赖，也不需要联网。

浏览器版的文件和修改只保存在当前页面内存中，刷新前应通过「查看修改」下载所需文件，并按提示放置到相应路径。有未保存修改时，离开页面会收到提示。
